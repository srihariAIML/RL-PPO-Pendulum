# PPO Pendulum-v1 Reinforcement Learning Project

## Project Overview

This project trains a Proximal Policy Optimization (PPO) agent to control the
continuous-action `Pendulum-v1` environment from Gymnasium.

The goal is to learn a policy that applies torque to keep the pendulum close to
the upright position while reducing unnecessary movement and control effort.

Gymnasium defines the Pendulum-v1 observation as three values:
`cos(theta)`, `sin(theta)`, and angular velocity. The action is one continuous
torque value in the range -2 to 2. The environment reward is highest when the
pendulum is upright, has low angular velocity, and uses little torque.

## Installation

Use Python 3.10 or newer if possible.

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

macOS/Linux:

```bash
source .venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Train the Agent

```bash
python train_ppo.py
```

The default training configuration is designed for a student project and can
be adjusted in the file. The script saves the trained model and a CSV file
containing episode rewards.

## Evaluate the Agent

After training:

```bash
python evaluate_ppo.py
```

The evaluation script runs several episodes and reports the average return.

To watch the agent:

```bash
python evaluate_ppo.py --render
```

## Main PPO Components

The implementation contains:

- Actor network for the continuous action policy
- Critic network for state-value estimation
- Gaussian action distribution
- PPO clipped objective
- Generalized Advantage Estimation (GAE)
- Entropy bonus for exploration
- Value-function loss
- Mini-batch PPO updates
- Multiple random-seed support

## Results

Do not enter estimated values in the final report or presentation. Run the
training and evaluation scripts and copy the actual values into the slides.

The `results/` folder is intended for the actual graph and CSV generated by
your experiment.

## Reproducibility

The training script accepts a seed:

```bash
python train_ppo.py --seed 42
```

For the final project, it is useful to run more than one seed and report the
mean and variation of evaluation performance.
